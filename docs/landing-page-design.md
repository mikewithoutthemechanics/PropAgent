# PropAgent Landing Page Design
## South African Real Estate Platform Marketing Page

---

## 1. Page Overview

**Purpose:** Convert property agents and landlords in South Africa to sign up for PropAgent's real estate management platform.

**Target Audience:**
- Property agents (individual and agency)
- Landlords with rental portfolios (5+ properties)
- Property managers managing multiple properties
- Real estate agencies seeking digital transformation

**Strategic Positioning:**
- PropAgent vs Property24: We provide backend management; Property24 is for listings
- Trust accounting compliance for South African regulations
- AI-powered automation to reduce administrative burden

## 6. Technical Specifications

### Responsive Breakpoints
- Desktop: 1200px+
- Tablet: 768px - 1199px
- Mobile: < 768px

### Animation Guidelines
- Hero fade-in: 0.6s ease-out on load
- Card hover: translateY(-4px), 0.3s
- Button hover: brightness(1.1), 0.2s
- Scroll-triggered: fade-up, stagger 0.1s

### Performance Targets
- First Contentful Paint: < 1.5s
- Largest Contentful Paint: < 2.5s
- Total page weight: < 500KB (excluding images)
